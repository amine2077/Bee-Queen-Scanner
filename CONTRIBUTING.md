# Contributing to Bee Queen Scanner 🐝

First off, thank you for considering contributing to **Bee Queen Scanner**! Contributions like yours help make open-source AI tools accessible for beekeepers worldwide.

## How Can I Contribute?

### 1. Reporting Bugs
- Use the [GitHub Issue Tracker](https://github.com/amine2077/Bee-Queen-Scanner/issues).
- Describe the bug clearly, including steps to reproduce, device model, and OS version.

### 2. Suggesting Enhancements
- Open a feature request issue explaining what feature you'd like to see and why it would be beneficial.

### 3. Submitting Pull Requests
1. **Fork** the repository.
2. Create a new feature branch: `git checkout -b feature/amazing-feature`.
3. Make your changes and test on a physical Android device.
4. Format your Dart code: `flutter format lib/`.
5. Commit your changes: `git commit -m 'Add some amazing feature'`.
6. Push to your branch: `git push origin feature/amazing-feature`.
7. Open a **Pull Request**.

## Code Style & Conventions
- Follow standard [Effective Dart](https://dart.dev/guides/language/effective-dart) guidelines.
- Keep widget implementations clean and modular.

Thank you for your support! 🍯
